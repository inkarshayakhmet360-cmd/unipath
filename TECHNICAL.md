# UniPath AI
# Technical Documentation

## 1. Общая информация о проекте

UniPath AI — это AI-powered образовательная система, предназначенная для помощи студентам при поступлении в зарубежные университеты.

Основная задача проекта — создать персонального AI-помощника, который анализирует индивидуальный профиль ученика и помогает построить понятный путь подготовки к поступлению.

Система объединяет:

- пользовательский профиль;
- базу университетов;
- искусственный интеллект;
- персональные рекомендации;
- систему подготовки.


Основная идея:

Пользователь вводит свои данные, система анализирует их и показывает, какие шаги необходимо выполнить для достижения цели.

# 2. Архитектура системы


Общая архитектура UniPath AI:
 USER

              ↓

      Questionnaire

              ↓

      Student Profile

              ↓

         Supabase

              ↓

      AI Processing Layer

              ↓

   Personalized Analysis

              ↓

              University Compare My Path
Matching Roadmap


Система состоит из трех основных уровней:


## 2.1 Frontend Layer

Отвечает за:

- интерфейс приложения;
- отображение данных;
- навигацию;
- взаимодействие пользователя.


Используемые технологии:

- React Native;
- Expo;
- TypeScript.


---

## 2.2 Backend Layer

Отвечает за:

- хранение данных;
- авторизацию пользователей;
- передачу информации между компонентами.


Используется:

Supabase.


Основные функции:

- User Authentication;
- Database Storage;
- Edge Functions.


---

## 2.3 AI Layer

AI слой отвечает за:

- анализ профиля;
- подбор университетов;
- создание рекомендаций;
- генерацию roadmap.

# 3. Frontend технологии


## React Native

React Native используется для разработки мобильного приложения.

Причины выбора:

- возможность создания приложения для разных платформ;
- быстрый процесс разработки;
- большое количество готовых компонентов.


Используется для:

- экранов приложения;
- кнопок;
- карточек университетов;
- пользовательского интерфейса.


---

## Expo

Expo используется как среда разработки React Native.


Основные возможности:

- быстрый запуск приложения;
- тестирование через Expo Go;
- упрощенная работа с мобильными устройствами.


---

## TypeScript

TypeScript используется вместо обычного JavaScript для повышения надежности.


Преимущества:

- контроль типов данных;
- уменьшение количества ошибок;
- более понятная структура проекта.
